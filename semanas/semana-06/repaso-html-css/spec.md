📝 spec.md: Bloque 01 - Header & Nav
Estructura HTML: Crear etiqueta <header> que envuelva todo el bloque superior.

Logo: Insertar logo.jpg dentro de un enlace <a> (por accesibilidad).

Menú: Usar etiqueta <nav> con una lista no ordenada <ul> y 7 elementos <li>.

Enlaces: Cada palabra (Explorar, Bosques...) irá dentro de un <a> con href="#".

CSS Reset: Aplicar box-sizing: border-box a todo para controlar las cajas.

CSS Layout: Usar display: flex en el <ul> para poner el menú en horizontal.

Estilo: Quitar decoración de enlaces (text-decoration: none) y puntos de lista (list-style: none).

Tipografía: Aplicar text-transform: uppercase solo desde CSS (según norma del PDF).
